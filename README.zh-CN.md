# zuowenpigai-essay

[English](README.md) | **简体中文**

一个**代理技能（agent skill）**，用于在 **作文批改平台（zuowenpigai / IN课堂 学生端）** 上写稿、改稿、提交。平台自带的「智能评测」会给每次提交打分，本技能把这条「评分 → 按批注改 → 再评」的循环变成可复用的流程。

真正难的不是「生成文字」，而是这三件事：

- **屏幕上题目是截断的。** `题目详情与材料` 是一个 disabled 的 `<textarea>`，完整题干只存在于它的 `value` / 可访问性树里。
- **编辑器对分段极其敏感。** 用 `\n\n` 粘贴会生成空 `<p>`，而评测是**按段落**给格式分——`行文规范` 会从 80+ 掉到 40～60，总分跟着塌。平台自己会加两个全角缩进，你再加一次就是双重缩进。
- **分数是异步回来的。** 点完智能评测卡片显示 `批改中`，之后可能短暂显示 `未提交`（其实已提交成功）——真分数在卡片里的 `总评`。

## 流程

1. **读完整题目** —— 从 textarea 的 value 拿完整题干，再读 `写前指导`（审题、立意、提纲），那基本就是评分口径。
2. **写正文** —— 写到字数下限的 1.3～1.5 倍，写具体场景与动作而不是景物罗列，安排一个「我」真正参与的贯穿意象。
3. **填入编辑器** —— 用一次 `paste` 事件粘贴全文，段间只放单个 `\n`；随后自检：空段落 0、段落数约 8～10、计数器与正文一致。
4. **评测** —— 智能评测 → 确定 → 刷新 → 打开卡片读 `总评` / `全文批注` / `提升建议`。
5. **按维度提分** —— 先修 `行文规范`（格式），再修 `结构严谨`（段落），然后用一次具体互动拉 `新颖`/`深刻`，最后删套语提 `文采`。最多 3 轮，到目标分就停，并报告最弱维度。
6. **只在明确要求时提交** —— 提交后确认卡片变成 `已提交` 再回复。

## 手册里最有价值的一条（有数据，不是感觉）

同一篇作文三次改稿，百分制：86.8 → 85.2（只换细节、格式照旧坏着）→ **90.7**（修格式、合并段落、补一个「我」参与的互动场景）。**光加细节反而掉分**。另一个案例 88 → 92 全程没重写，只是把「直白说理」换成物件与动作，并补一句伏笔。

## 边界

- 没有作者明确指示绝不提交——每次都会先问。
- 不编造引用、不虚构作者没有的经历；它润色作者已经写出来的东西。
- 请遵守你课程的 AI 使用规定。很多写作课要求提交的是本人原创作品，用它从头代写可能违规——先看教学大纲。

## 依赖

一个能控制浏览器的代理，以及在作文批改平台上的**已登录**会话（登录是人的事，技能不代输凭证）。
